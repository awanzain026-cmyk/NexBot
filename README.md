# NexBot — AI Chatbot Builder

A no-code SaaS platform that lets any business owner build a custom AI chatbot for their website in minutes.

**Source:** this repo

## What it does

- **4-step wizard builder** — no coding required
- **Real-time preview** powered by GPT-4o
- **Analytics dashboard** to track chatbot performance
- **One-click website embed**
- Includes a full demo build ("Ahmad's Restaurant") showing menu, hours, and FAQ handling out of the box

## Tech Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS, Framer Motion
- Three.js for interactive visuals
- GPT-4o via Sodeom's free AI proxy — no API key required
- Recharts for analytics

## Getting Started

```bash
git clone https://github.com/awanzain026-cmyk/NexBot.git
cd NexBot
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). No environment variables needed — it uses a free AI proxy out of the box, so it also works immediately after deploying to Vercel.
